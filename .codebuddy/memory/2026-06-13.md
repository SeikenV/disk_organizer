## OLLAMA_NUM_PARALLEL 配置
- `OLLAMA_NUM_PARALLEL` 是 Ollama 服务启动参数，运行时无法通过 API 修改，必须在启动前注入
- 修改 `scripts/setup_ollama.ps1`，新增 `-NumParallel` 参数（默认 4），在三个位置注入：
  1. `$env:OLLAMA_NUM_PARALLEL` — 当前进程
  2. `[Environment]::SetEnvironmentVariable(..., "User")` — 持久化用户级
  3. `$psi.EnvironmentVariables[...]` — 两个子进程（ollama list 触发服务 + ollama serve 回退）
- 注意：`ollama list` 触发的是 Windows 服务，服务可能不继承脚本子进程的环境变量——此时靠持久化的 `[Environment]::SetEnvironmentVariable` + 重启 Ollama 生效
